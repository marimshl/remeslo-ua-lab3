# RemesloUA

**RemesloUA** — онлайн-маркетплейс та спільнота українських майстрів ручної роботи (hand made).
Слоган: «Зроблено руками. Куплено серцем».

Навчальний проєкт з дисципліни «Веб-орієнтована розробка ПЗ», КПІ ім. Ігоря Сікорського.

| Лабораторна | Тема | Тег у репозиторії |
|---|---|---|
| ЛР2 | Створення структури веб-проєкту | `lab2` |
| ЛР3 | Використання CSS для оформлення та адаптації вебсайту | `lab3` |

## Структура проєкту

```
remeslo-ua/
├── css/
│   ├── style.css        # головний файл: збирає модулі через @import
│   ├── base.css         # змінні брендбуку, скидання, типографіка, списки, таблиці
│   ├── layout.css       # шапка, бургер-меню, сітки сторінок, підвал
│   ├── components.css   # кнопки, картки, бейджі, галерея, відгуки, адаптивна таблиця
│   ├── forms.css        # поля форм, стани фокусу та валідації
│   └── responsive.css   # медіазапити 480 / 768 / 1024 px, стилі для друку
├── images/              # оптимізовані SVG-зображення (логотип, товари, аватари, карта)
├── js/
│   └── main.js          # бургер-меню, валідація форм, фільтр каталогу, галерея
├── index.html           # Головна
├── catalog.html         # Каталог виробів із фільтрами
├── product.html         # Сторінка товару
├── about.html           # Про нас
├── contacts.html        # Контакти + форма зворотного зв’язку + тарифи доставки
├── login.html           # Вхід / Реєстрація
└── README.md
```

## Сторінки

| Сторінка | Файл | Основний вміст |
|---|---|---|
| Головна | `index.html` | Hero-банер, пошук, категорії, нові вироби, майстер тижня, підписка |
| Каталог | `catalog.html` | Фільтри (категорія, ціна, регіон), сортування, картки товарів, пагінація |
| Товар | `product.html` | Галерея, характеристики, кошик, картка майстра, відгуки, схожі товари |
| Про нас | `about.html` | Місія, переваги, умови для майстрів, команда |
| Контакти | `contacts.html` | Форма зворотного зв’язку, контакти, карта, таблиця тарифів доставки |
| Вхід / Реєстрація | `login.html` | Форми входу та реєстрації з вибором ролі |

## Застосовані технології CSS (ЛР3)

- **Модульна організація стилів** — п’ять CSS-файлів, об’єднаних у `style.css` директивою `@import`.
- **CSS-змінні (custom properties)** — кольори, шрифти, відступи та радіуси з брендбуку ЛР1 визначено один раз у `:root`.
- **CSS Grid** — макети сторінок: hero, сітка карток товарів, каталог «фільтри + товари», сторінка товару, контакти, авторизація, підвал.
- **Flexbox** — шапка, рядок меню, категорії-«пігулки», пошук, хлібні крихти, пагінація, картка майстра, форма «Додати в кошик».
- **Медіазапити, mobile-first** — базові стилі для телефона (від 320 px), розширення на 480 px (великі телефони), 768 px (планшети), 1024 px (десктоп); окремі стилі для друку та `prefers-reduced-motion`.
- **Бургер-меню** — на екранах до 1024 px меню ховається за кнопкою з анімацією «три лінії → хрестик», закривається клавішею Esc.
- **Адаптивна таблиця** — на телефоні й планшеті кожен рядок таблиці тарифів стає карткою з підписами полів (`data-label` + `::before`).
- **Валідація форм** — HTML5-атрибути (`required`, `type="email"`, `minlength`, `pattern`, `min`/`max`) + стилі помилок через `:user-invalid` та `[aria-invalid="true"]`, успіху — через `:user-valid`; повідомлення українською під полем.
- **Кросбраузерність** — вендорні префікси (`-webkit-`, `-moz-`) для `appearance`, `position: sticky`, `text-size-adjust`, згладжування шрифтів; уніфікований вигляд `select`, полів `number`/`search` і чекбоксів (`accent-color`).
- Препроцесори Sass/Less не використовувалися: змінні та модульність реалізовано засобами чистого CSS.

## Перевірка

- HTML усіх сторінок — [W3C Nu Html Checker](https://validator.w3.org/nu/): без помилок і попереджень.
- CSS усіх файлів — [W3C CSS Validator](https://jigsaw.w3.org/css-validator/), профіль CSS3 + SVG: 0 помилок.
- Відображення перевірено в Google Chrome 155 та Microsoft Edge 155 на ширинах 320, 375, 480, 768, 1024 і 1440 px — без горизонтальної прокрутки.

## Запуск

Відкрийте `index.html` у браузері або запустіть будь-який статичний сервер, наприклад:

```bash
npx serve .
```
