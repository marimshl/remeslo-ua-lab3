# RemesloUA

**RemesloUA** — онлайн-маркетплейс та спільнота українських майстрів ручної роботи (hand made).
Слоган: «Зроблено руками. Куплено серцем».

Навчальний проєкт з дисципліни «Веб-орієнтована розробка ПЗ», КПІ ім. Ігоря Сікорського.
Лабораторна робота №2 — створення структури веб-проєкту (статична HTML/CSS/JS-версія макету з ЛР1).

## Виконавці

- Зіберт Марі Мішель Сергіївна, група КІ-42

## Структура проєкту

```
remeslo-ua/
├── css/
│   └── style.css        # стилі: палітра й шрифти з брендбуку, адаптивна сітка
├── images/              # оптимізовані SVG-зображення (логотип, товари, аватари, карта)
├── js/
│   └── main.js          # мобільне меню, валідація форм, фільтр каталогу, галерея
├── index.html           # Головна
├── catalog.html         # Каталог виробів із фільтрами
├── product.html         # Сторінка товару
├── about.html           # Про нас
├── contacts.html        # Контакти + форма зворотного зв’язку
├── login.html           # Вхід / Реєстрація
└── README.md
```

## Сторінки

| Сторінка | Файл | Основний вміст |
|---|---|---|
| Головна | `index.html` | Hero-банер, пошук, категорії, нові вироби, майстер тижня, підписка |
| Каталог | `catalog.html` | Фільтри (категорія, ціна, регіон), сортування, картки товарів, пагінація |
| Товар | `product.html` | Галерея, характеристики, кошик, картка майстра, відгуки, схожі товари |
| Про нас | `about.html` | Місія, переваги, умови для майстрів, команда |
| Контакти | `contacts.html` | Форма зворотного зв’язку, контакти, карта, FAQ доставки |
| Вхід / Реєстрація | `login.html` | Форми входу та реєстрації з вибором ролі |

## Технічні особливості

- Семантична розмітка: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `address`.
- Доступність: `alt` для всіх зображень, `label` для полів, `aria-current`, `aria-live`, skip-link, фокус-стани.
- Адаптивна верстка (mobile-first breakpoints 900 px і 480 px), без сторонніх CSS-фреймворків.
- Усі сторінки пройшли перевірку [W3C Nu Html Checker](https://validator.w3.org/nu/) без помилок і попереджень.
- Зображення у форматі SVG (0,3–0,8 КБ кожне), `width`/`height` та `loading="lazy"` для зображень нижче першого екрана.

## Запуск

Відкрийте `index.html` у браузері або запустіть будь-який статичний сервер, наприклад:

```bash
npx serve .
```
